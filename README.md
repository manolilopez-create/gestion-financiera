# Gestión Financiera · 0653

Web app del módulo de Gestión Financiera (CFGS Administración y Finanzas, Comunitat Valenciana, modalidad semipresencial).

Se instala en iPhone/iPad desde Safari: **Compartir → Añadir a pantalla de inicio**. Funciona sin conexión una vez abierta.

Contenido: objetivos y contenidos, programación de aula, tutorías colectivas, actividades y material complementario de las unidades publicadas.
